## 🌟 Key Highlights

### 📱 1. 100% Phone & Mobile Compatibility
- **Off-Canvas Drawer Navigation**: On phone screens (`<= 768px`), the complete 65-lesson curriculum neatly hides behind a top-left hamburger menu (`☰`), sliding in smoothly with a single tap.
- **Auto-Closing Navigation**: Selecting any lesson automatically closes the mobile drawer and scrolls smoothly to the top of the lesson content.
- **Touch-Friendly Controls**: Large, accessible touch targets for quick quizzes, flashcards, language toggles, and view switchers.
- **Responsive Code Blocks**: Code snippets scroll horizontally (`overflow-x: auto`) without breaking the viewport or pushing layout boundaries.
- **Full-Width Responsive Modals**: The Grand Master Exam, Module Quizzes, and Quick Cheatsheet automatically expand to `95vw` on mobile screens with scrollable containers.
